closet console

Edits are written straight to GitHub from this page. Nothing runs in between — no server, no third party. Your token is stored only in this browser.

how to make a token
  1. Open fine-grained tokens ↗ and pick this repository under Repository access.
  2. Under Repository permissions, set Contents to Read and write.
  3. To open pull requests instead of committing directly, also set Pull requests to Read and write.
  4. Generate it, copy it, paste it above. A classic token with the repo scope works too.

A token in a browser can be read by anything that can run script on this page. Give it one repository and nothing more, and revoke it if you are unsure.
